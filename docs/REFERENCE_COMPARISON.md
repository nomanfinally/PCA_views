# Features worth bringing over from the older smartPCA viewer

Reviewed the local `01_github_alt/smartPCA-views` source (`app.js`, `style.css`, and `index.html`). These are existing capabilities in that viewer which would add something to the current application:

| Feature                   | Why it is useful                                                                                                                                                     | Suggested implementation                                                                        |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Nearby-sample multi-hover | Inspect several overlapping points at once. The older app searches a pixel radius and lists up to eight nearby samples. The current viewer shows the closest sample. | Add a proximity query using plotted screen coordinates; use a spatial index for large datasets. |
| Paste `.evec` contents    | Quickly inspect coordinates copied from a terminal or editor.                                                                                                        | Add a paste dialog that sends text through the existing parser and validation path.             |

Already carried over or retained: arbitrary PC pairs, pan and wheel/box zoom, fit visible/reset all, box/lasso selection, sample marking, six original palette families with lighter classic fills, additional polygon and triangle markers, filled/hollow markers with darker or black outlines, individual sample style editors, size/opacity, grayscale, label modes, draggable population callouts, population hulls and regression lines, square plots, crosshairs, population visibility, counts, title/subtitle, PNG export with preview, configurable legend positions and columns, separate marker fill/boundary transparency, per-population label styling, and standard chart aspect ratios.

This redesign uses the older viewer's compact white plot and floating legend as the layout reference. The toolbar is horizontal at the upper left. Controls are monochrome; population colors remain meaningful data colors. Legend search opens only when requested, entries are compact, and hidden populations remain visibly marked. Ordinary datasets use SVG markers with explicit dark outlines, while datasets above 5,000 samples use WebGL. Group labels have draggable plain, background, or boxed styles with separate centroid connections and retain their offsets for each PC pair.

The classic frame and subtle grid also follow the visual direction of the [smartSNP plotting vignette](https://christianhuber.github.io/smartsnp/articles/aDNA_smartpca_analysis.html), which uses ggplot2's `theme_bw()` and repelled population labels. Label placement here is manual; automatic label collision avoidance would be a separate enhancement.

[Vahaduo g25views](https://github.com/vahaduo/g25views) informs toolbar behavior. Controls that require separate base/projected G25 datasets or reprojection are not applicable to a single imported `.evec` file without extending the data model. The toolbar uses Lucide icons and a small custom lasso cursor. Palette definitions were adapted from the user’s local smartPCA viewer.
